# Malinga Hills Lodge — Portfolio Concept

A premium hospitality website concept created by Golden-Rhys Company.

## Features
- Responsive desktop and mobile layout
- English and Chichewa language switch
- Room, experience, story and journal sections
- Enquiry form with date validation
- Accessible mobile navigation
- Clear concept-project disclosure

## Important
Malinga Hills Lodge is a fictional demonstration brand. The enquiry form is intentionally front-end only and does not create real reservations.

## Render Static Site
- Root Directory: `hotel-demo`
- Build Command: leave blank
- Publish Directory: `.`

The site is plain HTML, CSS and JavaScript; no build step is required.
