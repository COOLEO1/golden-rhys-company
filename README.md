# Golden-Rhys Company

Premium bilingual (English / Chichewa) web development agency website and portfolio for the Malawi market.

## Repository layout
- `index.html`, `css/`, `js/`: agency website
- `hotel-demo/`: Malinga Hills Lodge hospitality concept
- `construction-demo/`: construction company concept (in development)
- `school-demo/`: private school concept (in development)
- `dealership-demo/`: car dealership concept (in development)

## Deploy agency website on Render
- Service type: Static Site
- Branch: main
- Root Directory: leave blank
- Build Command: leave blank
- Publish Directory: .

## Deploy each portfolio demo separately
Create a separate Render Static Site for each demo and set its Root Directory to the relevant folder (for example `hotel-demo`). Leave Build Command blank and use `.` as Publish Directory.
