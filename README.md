# Golden-Rhys Company

Premium bilingual (English / Chichewa) web development agency website and portfolio for the Malawi market.

## Repository layout

- `index.html`, `css/`, `js/`: agency website
- `hotel-demo/`: Freddie's Lodge independent hospitality website concept
- `construction-demo/`: Tithandizane Construction & Civils concept
- `school-demo/`: Nthanda Academy private school concept
- `dealership-demo/`: Mwayi Motors Malawi vehicle dealership concept

## Portfolio status

The four portfolio websites are demonstration concepts, not real client projects. Names, business details, project images and vehicle listings are illustrative and should not be represented as verified businesses, completed client work, live inventory or real offers.

Each demo is a self-contained static website and can be deployed independently.

## Deploy the agency website on Render

- Service type: Static Site
- Repository: `COOLEO1/golden-rhys-company`
- Branch: `main`
- Root Directory: leave blank
- Build Command: leave blank
- Publish Directory: `.`

## Deploy portfolio demos separately

Create one Render Static Site per demo:

| Demo | Root Directory | Publish Directory |
|---|---|---|
| Malinga Hills Lodge | `hotel-demo` | `.` |
| Northline Build Co. | `construction-demo` | `.` |
| Oakbridge Academy | `school-demo` | `.` |
| Motiv Motor House | `dealership-demo` | `.` |

For each service, use branch `main`, leave the Build Command blank, and set the Publish Directory to `.`.
